## About the Repository

This repository contains C++ programs developed as part of the **Object-Oriented Programming (OOPS)** course. The programs demonstrate file handling concepts, text and binary file operations, record management, file navigation, error handling, and practical real-world applications.

## Program Descriptions

### Code Book

| No. | Program                               | Description                                                                                             |
| --: | ------------------------------------- | ------------------------------------------------------------------------------------------------------- |
|   1 | `01_write_text_file.cpp`              | Creates a text file and writes data into it using `ofstream`.                                           |
|   2 | `02_read_file_line_by_line.cpp`       | Reads the contents of a text file line by line using `getline()`.                                       |
|   3 | `03_append_data_file.cpp`             | Adds new data to an existing text file using append mode.                                               |
|   4 | `04_copy_file.cpp`                    | Copies the contents of one text file into another file.                                                 |
|   5 | `05_count_lines_words_characters.cpp` | Counts lines, words, and characters present in a text file.                                             |
|   6 | `06_search_word_in_file.cpp`          | Searches for a specified word in a text file and counts its occurrences.                                |
|   7 | `07_store_student_records.cpp`        | Stores student roll number, name, and marks in a file.                                                  |
|   8 | `08_read_search_student_records.cpp`  | Reads student records and searches for a record using the roll number.                                  |
|   9 | `09_update_record_temp_file.cpp`      | Updates student records using a temporary file.                                                         |
|  10 | `10_file_pointer_navigation.cpp`      | Demonstrates file pointer navigation using `tellg()`, `tellp()`, `seekg()`, and `seekp()`.              |
|  11 | `11_binary_file_record_io.cpp`        | Writes and reads student records using binary file handling.                                            |
|  12 | `12_random_access_binary_file.cpp`    | Demonstrates random access for reading selected records from a binary file.                             |
|  13 | `13_file_error_handling.cpp`          | Demonstrates file error checking using stream status functions.                                         |
|  14 | `14_file_statistics_mini_project.cpp` | Calculates file statistics such as lines, words, characters, vowels, digits, and spaces.                |
|  15 | `15_student_record_manager.cpp`       | Implements a student record management system with add, display, search, update, and delete operations. |
|  16 | `16_library_record_mini_project.cpp`  | Implements a file-based library record system for managing books and their issue status.                |
